# Simple Dashboard Project

This is a basic multi-file dashboard project built with HTML and CSS.

## Files

- `index.html` - main dashboard page
- `styles.css` - shared styles
- `script.js` - small UI interactions
- `analytics.html` - analytics mock page
- `profile.html` - profile mock page
